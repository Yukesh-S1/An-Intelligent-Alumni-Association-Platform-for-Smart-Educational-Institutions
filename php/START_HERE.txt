  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

PROBLEM: Blank page
→ Press F12, check console for errors
→ Try: http://localhost/new/videocall.php?room=test123

PROBLEM: Stuck on "Initializing..."
→ Check browser permissions (camera/microphone)
→ Click lock icon in address bar
→ Set to "Allow"

PROBLEM: Stuck on "Waiting for peer..."
→ Make sure second person joined
→ Check they're using same room ID
→ Wait 10 seconds

PROBLEM: No audio
→ Check 🎤 button is NOT red
→ Check system volume
→ Click anywhere on page

PROBLEM: No video
→ Check 📹 button is NOT red
→ Close other apps using camera
→ Try different browser
